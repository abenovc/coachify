# Coachify

Помощник тренера по олимпиадному программированию: ученики и группы, карта тем, планы уроков, контесты, подбор задач с Codeforces и база задач прошлых олимпиад.

## Запуск

Откройте `index.html` двойным щелчком — приложение работает прямо в браузере.
Установка, сервер, регистрация и оплата не нужны.

Интернет нужен только для обращения к бесплатному публичному API Codeforces (архив задач, рейтинг и посылки учеников).

## Где лежат данные

Без входа в аккаунт ученики, уроки и заметки хранятся в браузере на этом компьютере (localStorage).
Если очистить данные браузера или открыть приложение в другом браузере, они не будут видны.

Чтобы данные не терялись, войдите через Google (кнопка «Войти» в меню или «Настройки → Аккаунт»):
данные сохраняются в аккаунте автоматически и подтягиваются на любом устройстве. Вход работает на сайте
и не работает, если открыть `index.html` из файла. Хранение — бесплатный тариф Firebase (Auth + Cloud Firestore),
проект `coaching-a9532`; правила доступа лежат в `firestore.rules` и вставляются в консоли Firebase (Firestore → Rules).

Файл из «Настройки → Резервная копия» остаётся запасным вариантом и способом перенести данные вручную.

## Разделы

- **Ученики** — профили, карта тем, статистика Codeforces, рекомендации «что дальше».
- **Уроки** — конструктор плана и задач под ученика, проверка домашки.
- **Контесты** — набор задач по рейтингу и темам, объявление для учеников, таблица результатов по посылкам на Codeforces.
- **Олимпиады** — 2680 задач и туров прошлых лет. Международные: IOI 1989–2026, APIO, CEOI, BOI, JOI, COCI и другие. Казахстан и СНГ: архив esep.cpfed.kz (Республиканская олимпиада, ЧРК, KBO), IZhO, ВсОШ и её этапы, ВКОШП, Открытая олимпиада, Технокубок, Интернет-олимпиады, соревнования Казахстана из тренировок Codeforces. Вкладка «Мои» — для своих задач (например, с esep.cpfed.kz). Можно откладывать на потом, отмечать решённое и разобранное по ученикам, записывать разбор, превращать тур в контест.
- **Темы** и **Подбор задач** — библиотека тем и поиск по архиву Codeforces.

## Файлы

- `js/topics.js` — библиотека тем: что рассказать, типичные ошибки, пререквизиты, теги Codeforces, классические задачи CSES. Можно править вручную.
- `js/olympiad-data.js` — база олимпиадных задач (собрана из архива oj.uz, с официального сайта IOI, из Codeforces и с esep-old.cpfed.kz).
- `js/cf.js` — запросы к Codeforces и алгоритм подбора задач.
- `js/store.js` — хранение данных в браузере.
- `js/sync.js` — вход через Google и синхронизация с аккаунтом.
- `js/app.js` — ученики, уроки, темы, подбор задач, настройки.
- `js/contests.js`, `js/olympiads.js` — контесты и олимпиады.
- `js/main.js` — запуск и переключатель темы; `css/style.css` — оформление.
